# 网页管理后台

## 部署后配置

要求 Docker Compose 2.30+。使用镜像时，请确认所选镜像已包含需要的功能；本地源码修改需重新构建镜像后部署。准备 compose.yaml 和 .env：

```bash
cp .env.docker.example .env
chmod 600 .env
openssl rand -hex 32
# 将生成的随机值填写为 GATEWAY_ADMIN_TOKEN；模型地址、Key、模型可留到后台填写。
docker compose up -d
```

本机访问 `http://127.0.0.1:18080/admin`（根路径 `/` 也显示后台）。未登录时会进入独立管理登录页：

- 用户名：`admin`
- 管理令牌：`.env` 中的 `GATEWAY_ADMIN_TOKEN`（至少 32 字符）

登录后使用 12 小时有效的签名 HttpOnly Cookie；后台可主动退出。API 仍支持 Bearer 管理令牌，方便受控运维脚本调用。没有配置令牌时管理入口关闭，不提供默认密码、匿名初始化或公网领取管理员功能。

远程服务器默认只绑定回环地址，推荐 SSH 隧道：

```bash
ssh -N -L 18080:127.0.0.1:18080 用户@服务器
```

然后在自己电脑打开上述网址。也可通过 HTTPS 反向代理访问，正确保留 Host，不要直接开放明文管理端口。共享令牌对应全部管理权限；请使用完毕后主动退出，并避免在共享设备上使用浏览器密码保存。

### `/admin` 返回 `management_disabled`

HTTP 503 表示容器没有读到至少 32 字符的 `GATEWAY_ADMIN_TOKEN`，不是登录密码输错。用 `openssl rand -hex 32` 生成令牌，填入部署目录的 `.env`（设置了 `GATEWAY_ENV_FILE` 时则修改它指定的文件），不要添加引号。保留原有的其他配置。使用部署时相同的 Compose 参数重建服务；仅执行 `restart` 不会加载新环境变量。

```bash
docker compose up -d --force-recreate gateway
docker compose exec -T gateway node -e 'console.log(`GATEWAY_ADMIN_TOKEN length: ${(process.env.GATEWAY_ADMIN_TOKEN ?? "").trim().length}`)'
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:18080/admin
```

第二条命令只打印令牌长度，不输出令牌。长度应至少为 32；最后一条命令不带凭据，预期返回 `303` 并跳转独立登录页，此时可以在浏览器用 `admin` 和令牌登录。如果修改了宿主机端口，请替换示例中的 `18080`。

## 页面功能

1. **运行概览**：按角色区分配置状态与当前配置的 API 测试结果、队列数量、微信轮询状态、最后成功时间、连续失败次数。
2. **模型设置**：按 admin/family 分别填写 URL、Key、模型、思考强度、API/ACP 模式；测试连接后保存。
3. **微信与权限**：获取二维码、自动刷新登录状态、切换账号角色、查看最近联系人、授权/撤销管理员。
4. **成员管理**：按账号/联系人分别设置聊天、画图权限和每日次数，查看今日使用；不授予管理员工具能力。
5. **生图设置**：独立的 Key、模型、尺寸、质量、响应格式、超时、并发及全站每日上限；保存不发付费请求。
6. **图片作品**：最近 100 条记录，查看已有图片，确认后向原联系人补发，不重新生成。
7. **调用诊断**：按微信回复的诊断编号查看安全错误分类和处理建议。
8. **任务管理**：最近 100 条任务、执行阶段、投递结果、错误码和审计详情；支持按状态筛选，人工关闭 needs_review；不重放。

家庭成员扫码成功只表示微信账号已绑定，模型使用该角色的独立配置。若管理员可以聊天、家庭成员提示未配置模型，请打开“模型设置”，选择“家庭用户 family”，填写 API 地址、Key、模型和接口协议，先测试连接，再点击“保存并生效”。只做普通聊天可选择“纯 API 聊天”。也可点击“从管理员配置复制给家庭聊天”，明确确认后复制已保存的配置，家庭模式固定为纯 API，随后测试连接；此操作会共享供应商 Key 的额度，不会授予管理员能力。家庭聊天无需添加管理员联系人授权，也无需切换为 admin。

若已保存 family 配置仍无法聊天，先查看家庭模型的连接测试结果，再检查“运行概览”的账号轮询状态和“任务管理”的失败记录。扫码绑定不验证上游模型可用性。

family 的 ACP 模式保留“普通聊天走 API，复杂任务走 ACP”的路由；纯 API 模式拒绝复杂工具任务。管理员 API 模式只聊天，ACP 模式支持工具。管理员工具能力很强，谨慎授权。

连接测试调用实际 API 后端，可能消耗额度；测试不保存模型配置，但会记录通过/失败、时间及配置指纹。修改 Key、地址、模型、协议、思考强度或执行方式后，旧测试结果不再作为当前配置的验证结果。测试不验证 ACP 安装、工具隔离或微信收发。配置保存不要求测试先成功，方便处理临时网络故障。

## 保存、生效与优先级

- 只保存用户选择的角色；另一个角色独立配置。Key 留空保留该角色已有 Key，首次配置且无环境 Key 时必须填写。
- 成功保存后替换该角色的后端，下次任务使用新配置；有正在执行/调度的任务时返回 409，让管理员稍后重试，不中断任务。
- 更换 ACP 地址、Key、模型等后不复用旧的持久 ACP 会话。微信消息记录不删除。
- 配置优先级：**该角色的后台配置 > 环境变量和微信内模型/供应商覆盖**。本版后台覆盖一旦保存，不提供网页重置到环境配置；后续修改请仍在后台完成。未在后台配置的角色继续沿用原有配置逻辑。
- 后台不改写宿主机 `.env`。部署参数（管理令牌、镜像、端口、数据卷）仍由 `.env` 管理。
- 没有模型 Key 时允许启动后台；AI 任务不会以“未配置”状态默默尝试执行，但绑定微信和内建命令仍可使用。已经有官方登录认证文件的原部署可沿用原机制。
- 容器入口发现已有后台配置后，不再从 `.env` 自动重写 Codex 认证文件。后台设置不会因为重启或镜像更新而被旧环境值覆盖。CLI doctor 等独立运维工具仍使用其原有环境配置，不代表后台覆盖后的运行后端；后台连接测试用于验证候选 API 配置。

## 凭据安全与备份

配置保存在 `DATA_DIR/.settings/models.enc`，AES-256-GCM 加密；卷内 `.settings/key` 为加密密钥，文件权限 0600、目录 0700。返回给浏览器的配置只有 `hasApiKey`，不返回原 Key，页面不使用 localStorage。

**加密密钥与密文同卷，不防拥有数据卷或宿主机权限的攻击者。** 备份包含二者，仍必须按敏感资产管理；完整备份/恢复需要同时保留这两个文件。损坏或丢失加密密钥时服务拒绝加载配置，不静默退回旧凭据。

网页模型设置写入要求管理认证、同源检查、JSON 内容类型及自定义请求头；页面使用 nonce CSP，用户输入通过 textContent 呈现。自定义 API URL 允许内网端点，这是管理员能力，不向非管理员开放；连接测试会把候选 Key 发到管理员指定地址，请确认目标可信。

## 生图与成员额度

启用步骤：

1. 在“生图设置”填写兼容 Images API 的地址（例如供应商的 `/v1` 根地址）、独立 Key 与图片模型，并开启功能。实际请求为 `POST {baseUrl}/images/generations`，每次 `n=1`。
2. 尺寸与质量按供应商要求填写。默认请求 `b64_json`；不接受 `response_format` 参数的接口请选择“供应商默认”。也支持供应商返回公共 HTTPS 图片链接。
3. 成员先在微信发送 `/whoami`，或从最近联系人选择。进入“成员管理”开启画图权限、设置每日次数。默认成员可聊天、不可画图。
4. 微信发送 `/画图 窗边晒太阳的橘猫` 或 `/image an orange cat`。生成结果保存在该会话的 outbox，随后以图片消息发送。图片最大为 10 MiB 与文件发送上限中的较小值。

每日用量按北京时间自然日统计；聊天上限 0 表示不限，画图上限至少 1。额度记录在提交前预留，失败、超时或停止后不会自动退还，用于约束尝试次数，不等同于供应商实际扣费。已授权且处于管理员模式的联系人绕过成员限制，但仍受全站生图上限限制。`/help`、`/whoami`、`/stop` 等内建命令不占用聊天次数。聊天次数在后端调用前记录，未配置或已拒绝的调用不会消耗次数。

图片发送失败后，先查看作品是否已生成。已有文件可在后台查看和保存；补发仅使用原作品与原联系人当前有效的微信会话，不生成新图、不占新增画图次数。微信会话无效时，请先让该联系人发送一条消息。投递结果不确定时补发可能重复送达。重启会把未完成生成标为待人工检查、发送中标为不确定，不自动重跑。配置修改对新任务生效，已开始的生图使用原配置完成。

作品列表、图片文件和补发接口都需要管理认证；不提供公开图片链接。文件清理后查看返回 410，记录仍保留。作品文件存相对路径，迁移 DATA_DIR 后仍可从恢复后的 outbox 读取。视频生成与发送未接入。

## 当前验证边界

`pnpm verify` 从源码执行严格类型检查、清理重建、回归测试和隔离启动冒烟。自动测试使用模拟供应商及微信传输，覆盖权限、次数、配置指纹、图片结果保留与补发等流程，不调用真实付费接口。真实浏览器显示、微信扫码、微信图片展示、模型供应商兼容性、ACP 沙箱和部署镜像仍需在目标环境验收。
