# 网页管理后台

## 部署后配置

要求 Docker Compose 2.30+，本批代码已构建并发布到所选镜像。只需准备 compose.yaml 和 .env：

```bash
cp .env.docker.example .env
chmod 600 .env
openssl rand -hex 32
# 将生成的随机值填写为 GATEWAY_ADMIN_TOKEN；模型地址、Key、模型可留到后台填写。
docker compose up -d
```

本机访问 `http://127.0.0.1:18080/admin`（根路径 `/` 也显示后台）。未登录时会进入独立管理登录页：

- 用户名：`admin`
- 管理令牌：`.env` 中的 `GATEWAY_ADMIN_TOKEN`（至少 32 字符）

登录后使用 12 小时有效的签名 HttpOnly Cookie；后台可主动退出。API 仍支持 Bearer 管理令牌，方便受控运维脚本调用。没有配置令牌时管理入口关闭，不提供默认密码、匿名初始化或公网领取管理员功能。

远程服务器默认只绑定回环地址，推荐 SSH 隧道：

```bash
ssh -N -L 18080:127.0.0.1:18080 用户@服务器
```

然后在自己电脑打开上述网址。也可通过 HTTPS 反向代理访问，正确保留 Host，不要直接开放明文管理端口。共享令牌对应全部管理权限；请使用完毕后主动退出，并避免在共享设备上使用浏览器密码保存。

### `/admin` 返回 `management_disabled`

HTTP 503 表示容器没有读到至少 32 字符的 `GATEWAY_ADMIN_TOKEN`，不是登录密码输错。用 `openssl rand -hex 32` 生成令牌，填入部署目录的 `.env`（设置了 `GATEWAY_ENV_FILE` 时则修改它指定的文件），不要添加引号。保留原有的其他配置。使用部署时相同的 Compose 参数重建服务；仅执行 `restart` 不会加载新环境变量。

```bash
docker compose up -d --force-recreate gateway
docker compose exec -T gateway node -e 'console.log(`GATEWAY_ADMIN_TOKEN length: ${(process.env.GATEWAY_ADMIN_TOKEN ?? "").trim().length}`)'
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:18080/admin
```

第二条命令只打印令牌长度，不输出令牌。长度应至少为 32；最后一条命令不带凭据，预期返回 `401`，此时可以在浏览器用 `admin` 和令牌登录。如果修改了宿主机端口，请替换示例中的 `18080`。

## 页面功能

1. **运行概览**：队列数量、微信轮询状态、最后成功时间、连续失败次数。
2. **模型设置**：按 admin/family 分别填写 URL、Key、模型、思考强度、API/ACP 模式；测试连接后保存。
3. **微信与权限**：获取二维码、自动刷新登录状态、切换账号角色、查看最近联系人、授权/撤销管理员。
4. **任务管理**：最近 100 条任务、阶段/错误码/审计详情、人工关闭 needs_review；不重放。

family 的 ACP 模式保留“普通聊天走 API，复杂任务走 ACP”的路由；纯 API 模式拒绝复杂工具任务。管理员 API 模式只聊天，ACP 模式支持工具。管理员工具能力很强，谨慎授权。

连接测试调用实际 API 后端，可能消耗额度；测试不会保存配置，也不验证 ACP 安装、工具隔离或微信收发。配置保存不要求测试先成功，方便处理临时网络故障。

## 保存、生效与优先级

- 只保存用户选择的角色；另一个角色独立配置。Key 留空保留该角色已有 Key，首次配置且无环境 Key 时必须填写。
- 成功保存后替换该角色的后端，下次任务使用新配置；有正在执行/调度的任务时返回 409，让管理员稍后重试，不中断任务。
- 更换 ACP 地址、Key、模型等后不复用旧的持久 ACP 会话。微信消息记录不删除。
- 配置优先级：**该角色的后台配置 > 环境变量和微信内模型/供应商覆盖**。本版后台覆盖一旦保存，不提供网页重置到环境配置；后续修改请仍在后台完成。未在后台配置的角色继续沿用原有配置逻辑。
- 后台不改写宿主机 `.env`。部署参数（管理令牌、镜像、端口、数据卷）仍由 `.env` 管理。
- 没有模型 Key 时允许启动后台；AI 任务不会以“未配置”状态默默尝试执行，但绑定微信和内建命令仍可使用。已经有官方登录认证文件的原部署可沿用原机制。
- 容器入口发现已有后台配置后，不再从 `.env` 自动重写 Codex 认证文件。后台设置不会因为重启或镜像更新而被旧环境值覆盖。CLI doctor 等独立运维工具仍使用其原有环境配置，不代表后台覆盖后的运行后端；后台连接测试用于验证候选 API 配置。

## 凭据安全与备份

配置保存在 `DATA_DIR/.settings/models.enc`，AES-256-GCM 加密；卷内 `.settings/key` 为加密密钥，文件权限 0600、目录 0700。返回给浏览器的配置只有 `hasApiKey`，不返回原 Key，页面不使用 localStorage。

**加密密钥与密文同卷，不防拥有数据卷或宿主机权限的攻击者。** 备份包含二者，仍必须按敏感资产管理；完整备份/恢复需要同时保留这两个文件。损坏或丢失加密密钥时服务拒绝加载配置，不静默退回旧凭据。

网页模型设置写入要求管理认证、同源检查、JSON 内容类型及自定义请求头；页面使用 nonce CSP，用户输入通过 textContent 呈现。自定义 API URL 允许内网端点，这是管理员能力，不向非管理员开放；连接测试会把候选 Key 发到管理员指定地址，请确认目标可信。
